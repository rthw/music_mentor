# Файлы ученика

Эту папку наставник не перезаписывает при обновлении: здесь всё твоё.

- `profile.md` — кто ты: интересы, цели, версия Live и статусы тем. Наставник заполняет его сам и
  обновляет в конце сессии; ты можешь поправить.
- `log.jsonl` — журнал сессий, по строке JSON на сессию: `{"date","did","worked","next"}`.
- `snapshots/` — снимки твоих проектов, нужны `project_diff`, чтобы показать, что изменилось с
  прошлого раза. Руками не трогай.
