# Файлы ученика

Эту папку агент не перезаписывает при обновлении: здесь всё твоё.

- `profile.md` — кто ты: интересы, цели, версия Live и статусы тем. Агент заполняет его сам и
  обновляет в конце сессии; ты можешь поправить.
- `log.jsonl` — журнал сессий, по строке JSON на сессию: `{"date","did","worked","next"}`.
- `snapshots/` — снимки твоих проектов, нужны `project_diff`, чтобы показать, что изменилось с
  прошлого раза. Руками не трогай.
- `recipes/` — рецепты: приёмы и упражнения, которые агент запомнил именно для тебя (по скиллу на папку,
  файл `SKILL.md`). Можно читать и править, можно удалить лишнее.
- `my_tools/` — свои функции агента (расширения pi), дописанные по твоей просьбе. См. README внутри.
- `my_tools_disabled` — появляется, когда функции выключены (внутри — почему). Удалишь файл вручную —
  вернётся только после «включи мои функции».
- `wishes.md` — заявки автору, которые ты разрешил отправить: что ушло и что ждёт сети.
