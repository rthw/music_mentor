# Мои функции

Сюда агент дописывает маленькие функции (расширения pi), если ты его об этом попросил. Файлы — в `extensions/`.
Обновление агента эту папку не трогает. Если одна из функций сломалась и агент не стартует, он сам перезапустится
без них и скажет об этом; «почини мои функции» — и он разберётся. «Выключи мои функции» — отключит их все.
