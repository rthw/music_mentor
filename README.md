# music_mentor

Наставник по музыке и Ableton Live для [pi](https://pi.dev) (модель DeepSeek). Он читает твои проекты
Ableton (Live 10, 11 и 12), считает по нотам теорию — тональность, аккорды, ритм, диапазоны — и объясняет
по-русски, что в треке происходит и что можно сделать дальше.

Проект в работе: сейчас готово чтение проектов `.als`. Установщик и подключение к запущенному Live появятся
следующими.

## Что умеет сейчас

Пишешь обычным текстом, наставник сам вызывает инструменты:

- «Какие у меня есть проекты?» — `project_list`: ищет `.als` в Документах (в том числе в OneDrive) и на рабочем столе;
- «Что в этом проекте?» — `project_summary`: темп, размер, треки, устройства, клипы;
- «Покажи ноты клипа» — `clip_notes`;
- «Что тут с гармонией и ритмом?» — `project_analysis`: тональность, аккорды по тактам, бас, ритм, диапазоны, энергия;
- «Что я изменил с прошлого раза?» — `project_diff`.

Проект при этом не нужно открывать в Live, и ничего в нём не меняется: файл только читается.

## Запуск

Нужны [pi](https://pi.dev) и Node.js 22.18 или новее.

```sh
pi install <папка или git-адрес этого репозитория>
cd <рабочая папка>
pi
```

Проверка кода: `npm test` (зависимостей ставить не нужно).
